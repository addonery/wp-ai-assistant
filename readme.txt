Use your favourite AI model for writing in WordPress. Generate thumbnails and excerpts automatically with ChatGPT, Gemini, or Grok.

== Description ==

Blogger AI Assistant is a powerful WordPress plugin that integrates with leading AI services to help you create content more efficiently. Whether you're writing blog posts, articles, or any other content, this plugin automates the creation of thumbnails and excerpts using artificial intelligence.

= Key Features =

* **Multiple AI Service Support**: Choose from ChatGPT (OpenAI), Gemini (Google), or Grok (xAI)
* **Automatic Thumbnail Generation**: Generate professional thumbnails for your posts based on content
* **Automatic Excerpt Generation**: Create SEO-friendly excerpts (120-160 characters) automatically
* **Site Context Configuration**: Provide context about your site to generate more accurate and relevant content
* **API Connection Testing**: Test your API key connection before using the plugin
* **Easy Configuration**: Simple settings page to configure your preferred AI service and API key
* **Smart Image Sizing**: Automatically adjusts thumbnail size based on your WordPress thumbnail settings

= How It Works =

1. Configure your API key and select your preferred AI service (ChatGPT, Gemini, or Grok)
2. Optionally add site context to help the AI understand your content style
3. When editing a post, use the AI assistant to generate thumbnails and excerpts
4. The plugin automatically creates and attaches generated images to your posts

= Supported AI Services =

* **ChatGPT (OpenAI)**: Uses DALL-E 3 for image generation and GPT-3.5-turbo for text generation
* **Gemini (Google)**: Uses Gemini 2.5 Flash Image for images and Gemini 1.5 Flash for text
* **Grok (xAI)**: Uses Grok-2-image for image generation and Grok-4-1-fast-non-reasoning for text

== Installation ==

1. Upload the `blogger-ai-assistant` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'WP AI Assistant' in the admin menu
4. Enter your API key for your chosen AI service
5. Select your preferred AI service (ChatGPT, Gemini, or Grok)
6. Optionally add site context to improve content generation
7. Test your API connection to ensure everything is working
8. Start using the AI assistant in your post editor

= Getting API Keys =

* **ChatGPT**: Visit [OpenAI API Keys](https://platform.openai.com/api-keys) to create a new secret key
* **Gemini**: Visit [Google AI Studio](https://aistudio.google.com/app/apikey) to create a new API key
* **Grok**: Visit [xAI Console](https://console.x.ai) to create a new API key

== Frequently Asked Questions ==

= Do I need an API key? =

Yes, you need an API key from one of the supported AI services (ChatGPT, Gemini, or Grok) to use this plugin.

= Which AI service should I use? =

All three services work well. Choose based on your preference, pricing, and availability in your region.

= How much does it cost? =

The plugin is free. However, you may incur costs from the AI service providers based on their pricing plans. Check each service's pricing page for current rates.

= Can I use multiple AI services? =

You can configure one service at a time. Switch between services in the settings page as needed.

= What image sizes are supported? =

The plugin automatically detects your WordPress thumbnail settings and generates images in appropriate sizes (1024x1024, 1792x1024, or 1024x1792).

= How long are generated excerpts? =

Excerpts are automatically generated to be between 120-160 characters, optimized for SEO.
